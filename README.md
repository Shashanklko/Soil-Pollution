# Soil Pollution Awareness Website

This project is a simple website designed to raise awareness about soil pollution, its causes, effects, and potential solutions. It is built using HTML and CSS for front-end design.

## Features

- **Home Page:** Provides an introduction to soil pollution and its importance.
- **Causes:** Highlights the major causes of soil pollution.
- **Effects:** Explains the negative consequences of soil pollution on the environment and human health.
- **Solutions:** Offers potential solutions to reduce and prevent soil pollution.
- **Contact Us:** Includes a contact form for feedback or inquiries.
  
## Tech Stack

- **HTML:** For structuring the content.
- **CSS:** For styling the website, making it visually appealing and easy to navigate.
